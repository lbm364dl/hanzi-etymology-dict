seal manifest containing real downloaded seal SVGs for both graphs. Research had
found unrelated search results and general interfaces. The pipeline was withholding
useful local discovery information rather than lacking all suitable candidate material.

`Runner.run` now supplies `local_glyph_hints` to research and glyph research. It
collects explicit graph fields, looks up existing files in the local manifest, and
passes at most three leads per named graph. Leads include their exact stored image
URL, corresponding Commons file page and local path. They carry no invented license,
period, source authority or approval. Agents must inspect the file page and image,
verify rights and identity, and justify any selection against the explanation.
Running prose does not silently add unrelated graph candidates.

A regression test checks exact graph scoping, missing-file exclusion, URL encoding,
unverified status and preservation of agent inputs. All 92 pipeline tests pass.
