## Pipeline improvement

Image retries previously remembered only the latest failed candidate list. After
candidate A failed and then candidate B failed, candidate A could return in a third
attempt. The glyph-research loop now retains the complete failure set for the run,
passes it to subsequent research, and rejects a repeated failed ID or exact URL before
another download. Local seal-file hints filter these failed URLs as well, since a
stored manifest link can be stale.

A regression simulates A returning 404, B returning 404, then a proposed return to A.
Only A and B are requested; the third proposal is rejected. Local hint filtering is
also checked. All 94 pipeline tests pass.
