# Current senses and language scope

The 日/月/木 smoke exposed recurring status and language errors. 日 retained
Japanese-only senses from imported kanjidic metadata in a Chinese cohort entry.
木 described present-day tree/wood uses with modern dictionary support but marked
them historical. 月 reviews confused historical with obsolete and requested
earliest priority from a dated example while the intended ordinary sense was current.

Writer guidance now makes these contracts explicit: consulted current dictionaries
support current listed senses in their identified language; historical does not
mean extinct; current uses can have separately qualified ancient examples; imported
multilingual glosses need language-specific verification. No historical-to-current
semantic bridge is invented by a status label.

Source jobs pass the article/dossier/cohort target language (default Chinese for
legacy HSK source jobs) to research/authorship and advisory review packets. An
explicit Japanese article/dossier language is preserved. This does not certify or
rewrite existing entries. A packet test verifies the HSK default; affected
characters require genuine new authored repairs and independent reviews.
