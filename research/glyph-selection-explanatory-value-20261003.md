# Historical glyphs need explanatory value

The repeated 好/学 visual reviews expose a broader selection problem alongside
false geometry: a usable modern redraw does not necessarily illuminate the
entry's explanation. Requiring display whenever any licensed candidate exists
encourages decorative images, unjustified early-form inferences and elaborate
stroke captions that distract from the sourced character account.

The user project standard is to select historical glyphs only when they help
explain the entry. The glyph research instruction now explicitly permits an
empty selection when researched available forms lack that explanatory value,
with actual searches, inspected sources and cited relevance limits retained.
Useful sourced candidates still go through independent acquired-pixel review;
a web tool's inability to view pixels alone is not grounds for omission.

This is not permission to suppress a source disagreement or avoid necessary
form research. Meaningful contrasts such as script-specific shape changes,
component replacement or attested variant arrangements should be illustrated
when verified reusable evidence is available. Independent review and rights/
identity/provenance gates remain required. Prompt changes certify no old entry;
the current 好 and 学 repairs require fresh actual author/curator/review work.
